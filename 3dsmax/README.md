# Скрипты 3ds Max (MaxScript)

- `taksa.ms` — такса (практическая по NURBS/сопряжению поверхностей): тело, шея и голова — одна поверхность по поперечным сечениям (как U-Loft), лапы, уши, хвост, глаза, нос, материалы.
- `maska.ms` — маска (практическая №10, лоскутное моделирование): симметричный каркас лица с прорезями глаз и рта → Editable Patch → Shell → TurboSmooth.

Запуск: **Scripting → Run Script…** и выбрать файл. Повторный запуск удаляет старую версию модели.
В `maska.ms` можно поменять `USE_PATCH` и `STEP` вверху файла.
