# Скрипт 3ds Max (MaxScript)

`sobaka_i_maska.ms` — один файл, строит сразу:
- **собаку из NURBS-поверхностей** (практическая по NURBS, рис. 8.3): туловище с шеей и головой, 4 лапы, хвост, уши — все поверхности в одном NURBS-объекте `Sobaka_NURBS`, их можно сопрягать (Blend/Fillet) в панели Modify;
- **маску** справа (практическая №10, рис. 9.5): каркас лица с прорезями глаз и рта → Editable Patch → Shell → TurboSmooth.

Запуск: **Scripting → Run Script…**. Повторный запуск удаляет старые модели.
