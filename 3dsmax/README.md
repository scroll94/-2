# Скрипт 3ds Max (MaxScript)

`taksa_i_maska.ms` — один файл, строит сразу:
- **таксу** (тело, шея и голова — одна гладкая поверхность по сечениям, как U-Loft; лапы, уши, хвост, глаза, нос, материалы);
- **маску** справа от неё (каркас лица с прорезями глаз и рта → Editable Patch → Shell → TurboSmooth).

Запуск: **Scripting → Run Script…** и выбрать файл. Повторный запуск удаляет старые модели.
В части маски можно поменять `USE_PATCH` и `STEP`.
